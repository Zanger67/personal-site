# zang.dev

My personal website, live at [zang.dev](https://zang.dev).

A mostly for-fun portfolio and playground — projects, writing, experience, and the odd easter egg. Built on my own [personal-site-template](https://github.com/Zanger67/personal-site-template), a static [Astro](https://astro.build) site where the layout and structural work happens first before landing here with real content.

Visits are tracked with [GoatCounter](https://www.goatcounter.com), a privacy-friendly, cookieless analytics tool.
